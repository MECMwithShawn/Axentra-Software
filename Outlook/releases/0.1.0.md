Released 2026-10-19 as a GitHub **pre-release** (tag `outlook-v0.1.0`). Linux only.

Check the download before installing:

```bash
sha256sum axentra-outlook_0.1.0-1_amd64.deb
sudo apt install ./axentra-outlook_0.1.0-1_amd64.deb
```

## Build

- Source: [`../source/`](../source/), snapshot of commit `6926c2f`. The binary was built at `5a771b9`; the
  commits after it change only packaging and documentation, not the program.
- `cargo build --release --locked -p axentra-desktop` with rustc 1.99.1 on Zorin OS 18.1 x86_64, then
  `python3 packaging/linux/package.py --output dist`.
- Package `axentra-outlook` 0.1.0-1, amd64, about 9.6 MB (37 MB installed). Depends on libwebkit2gtk-4.1-0,
  libgtk-3-0t64, libsoup-3.0-0, libssl3t64, libxdo3 and xdg-utils, among others.
