# Axentra Outlook 0.1.3 (pre-release)

Released 2026-10-20 as a GitHub **pre-release** (tag `outlook-v0.1.3`). Linux only. Upgrades 0.1.0, 0.1.1 or
0.1.2 in place; your data and signed-in accounts are kept.

```bash
sha256sum axentra-outlook_0.1.3-1_amd64.deb
sudo apt install ./axentra-outlook_0.1.3-1_amd64.deb
```

## What's new

Resizable Settings and other dialogs with remembered sizes, and compose and read pop-outs you can move and
resize, plus everything in 0.1.2 (merged Outlook-style title bar) and 0.1.1 (encrypted monthly backups to
OneDrive, remembered Microsoft client ID). See the [changelog](../CHANGELOG.md).

## Build

- Source: [`../source/`](../source/), snapshot of commit `fc2520f`.
- `cargo build --release --locked -p axentra-desktop` (rustc 1.99.1, Zorin OS 18.1 x86_64), then
  `python3 packaging/linux/package.py --output dist`. No build warnings in debug or release.
- Package `axentra-outlook` 0.1.3-1, amd64, about 10 MB (39 MB installed). Same dependencies as 0.1.0.

## Status
