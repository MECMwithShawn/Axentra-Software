# Axentra Mail 0.1.9 (pre-release)

Released 2026-11-17 as a GitHub **pre-release** (tag `outlook-v0.1.9`). Linux only. Upgrades Axentra Mail 0.1.8
and Axentra Outlook 0.1.0–0.1.7 in place; your data and signed-in accounts are kept. Quit the app before installing.

## What's new

- **Replacement shipments keep their own status.** When a shop re-sends an order under new tracking numbers, an
  earlier delivery notice or a support reply that mentions the first delivery no longer marks the new parcels as
  delivered. 0.1.8 was built without this fix.
- **Packages updates as mail syncs**, has a refresh button, and shows the last email update for each shipment. The
  Track shortcut opens a parcel that's still on its way first.
- The first start after upgrading checks your orders again in the background.

See the [changelog](../CHANGELOG.md).

## Build

- Source: [`../source/`](../source/), snapshot of commit `6e2be7d`.
- `cargo build --release --locked -p axentra-desktop` (Zorin OS 18.1 x86_64), then
  `python3 packaging/linux/package.py --output dist`. No clippy warnings.
- Package `axentra-outlook` 0.1.9-1, amd64, about 72 MB (110 MB installed).
