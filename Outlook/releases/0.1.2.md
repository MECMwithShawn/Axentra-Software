# Axentra Outlook 0.1.2 (pre-release)

Released 2026-10-20 as a GitHub **pre-release** (tag `outlook-v0.1.2`). Linux only. Upgrades 0.1.0 or 0.1.1 in
place; your data and signed-in accounts are kept.

sha256sum axentra-outlook_0.1.2-1_amd64.deb

## What's new

The merged Outlook-style title bar, plus everything in 0.1.1 (encrypted monthly backups to OneDrive,
remembered Microsoft client ID). See the [changelog](../CHANGELOG.md).

## Build

- Source: [`../source/`](../source/), snapshot of commit `0f6f30e`.
- `cargo build --release --locked -p axentra-desktop` (rustc 1.99.1, Zorin OS 18.1 x86_64), then
  `python3 packaging/linux/package.py --output dist`. No build warnings in debug or release.
- Package `axentra-outlook` 0.1.2-1, amd64, about 10 MB (39 MB installed). Same dependencies as 0.1.0.

## Status

- 417 automated tests passed. The title bar was tried by hand on GNOME (X11). Not code-signed; VirusTotal scan
  pending (see [security](../security/virustotal.md)).
