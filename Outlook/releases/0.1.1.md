## What's new

See the [changelog](../CHANGELOG.md#011-pre-release-2026-10-19): encrypted monthly backups to OneDrive with
restore, remembered Microsoft client ID, cross-module actions, account status, RSVP sync and new Mail settings.

## Build

- Source: [`../source/`](../source/), snapshot of commit `da0c289`.
- `cargo build --release --locked -p axentra-desktop` (rustc 1.99.1, Zorin OS 18.1 x86_64), then
  `python3 packaging/linux/package.py --output dist`. No build warnings in debug or release.
- Package `axentra-outlook` 0.1.1-1, amd64, about 10 MB (39 MB installed). Same dependencies as 0.1.0.
