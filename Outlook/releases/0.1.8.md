# Axentra Mail 0.1.8 (pre-release)

Released 2026-11-16 as a GitHub **pre-release** (tag `outlook-v0.1.8`). Linux only. Upgrades Axentra Outlook
0.1.0–0.1.7 in place; your data and signed-in accounts are kept. Quit the app before installing.

```bash
sha256sum axentra-outlook_0.1.8-1_amd64.deb
sudo apt install ./axentra-outlook_0.1.8-1_amd64.deb
```

## What's new

**Now called Axentra Mail.** The window, Settings › About, the app menu, the icon and Axentra Command all say
Axentra Mail. It takes the place of the earlier Axentra Mail app: the package conflicts with and replaces
`axentra-mail`, so installing it removes the old app, and its Command entry uses the id `mail`. The package,
program and data folders keep the name `axentra-outlook`, so existing mail, accounts and settings carry over.
See the [changelog](../CHANGELOG.md).

## Build

- Source: [`../source/`](../source/), snapshot of commit `cba22dc`.
- `cargo build --release --locked -p axentra-desktop` (Zorin OS 18.1 x86_64), then
  `python3 packaging/linux/package.py --output dist`. No clippy warnings.
- Package `axentra-outlook` 0.1.8-1, amd64, about 72 MB (110 MB installed).
