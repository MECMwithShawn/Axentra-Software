# Axentra Outlook 0.1.7 (pre-release)

Released 2026-11-05 as a GitHub **pre-release** (tag `outlook-v0.1.7`). Linux only. Upgrades 0.1.0–0.1.5 in
place; your data and signed-in accounts are kept. Quit Axentra Outlook before installing. There was no separate
0.1.6 release; its changes are included here.

## What's new

Packages (orders and deliveries found in your mail, with progress), Topics and auto-archive into topic folders,
search by meaning and smarter keyword search, an automatic junk filter, an optional Local AI review pilot, and the
Home › Spam & AI menu. Also: Save picture as and Copy picture, folders that return you to the list, Close and
Minimize while writing, arranging and hiding folders, and composing from other apps. See the
[changelog](../CHANGELOG.md).

**Behaviour change:** the junk filter is on by default and moves clearly junk new mail from senders you've never
dealt with to Junk Email, also on the server. Turn it off under Home › Spam & AI.

## Build

- Source: [`../source/`](../source/), snapshot of commit `04154dd`.
- `cargo build --release --locked -p axentra-desktop` (Zorin OS 18.1 x86_64), then
  `python3 packaging/linux/package.py --output dist`, which downloads the search model once. No clippy warnings.
- Package `axentra-outlook` 0.1.7-1, amd64, about 72 MB (110 MB installed). The size is mostly the search model,
  BAAI/bge-small-en-v1.5 (MIT License), which runs on this computer.
