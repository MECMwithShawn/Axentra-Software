## What's in it

- **Backgrounds:** Bing daily image (4K where supported), Windows Spotlight and Unsplash photos; favorites,
  your own uploads, gradients; daily or per-tab rotation
- **Dashboard:** clock, greeting or mantras, main focus, daily quote, world clocks, search, quick links
- **Weather:** 6-day forecast; city search with suggestions; device location with an automatic approximate
  fallback when Windows Location services are off
- **Reminders:** birthdays, anniversaries, bills, events; yearly/monthly/weekly repeats; notifications up to a
  month ahead; dashboard countdowns; `.ics` import and export
- **Habits:** schedules, streaks, completion rate, heatmap, daily reminders
- **Tab stash:** from the new tab, the toolbar button, `Alt+Shift+S` or right-click
- **Productivity:** todo lists, notes, focus timer with notifications, breathing exercises, zen mode,
  soundscapes
- **Favorites bar** with folders on the new tab and, by default, on every website (always visible, moving the
  page down, or sliding down; see-through glass or solid; per-site choices,
  `Alt+Shift+F` to show or hide it)
- New Axentra Horizon logo, matching the Axentra suite
- Links to local files and network servers with an up/down indicator
- Keyboard shortcuts, backup and restore, settings synced across devices

## Known limitations

- The website favorites bar can't appear on `edge://` pages, the Add-ons store or PDFs. On a site whose layout
  doesn't suit an always-visible bar, choose *Slide down* or *Hide on this site* from the bar's ⋯ menu.
- Not yet on the Microsoft Edge Add-ons store; install unpacked (see the [README](../README.md#installation)).
  Edge may offer to turn off developer-mode extensions at startup; see
  [If Edge turns Horizon off](../README.md#if-edge-turns-horizon-off). The store release is planned ([store/](../store/)).
- Precise weather location needs Windows Location services turned on; otherwise the location is approximate
  (city level) unless you choose a city.
- Soundscapes play while a new tab page is open in the browser.
