# Linux / Zorin support

Verified 2026-10-17 on Zorin OS 18.1 (Ubuntu 24.04), x86_64. All nine development previews are installed locally and available from the application menu. No public Linux installer release is available yet.

The installed preview bundles the official 7-Zip 26.04 Linux engine and its license notices. | RAR creation needs a separately installed and licensed Linux RAR writer. No RAR writer is bundled. File associations are offered by the desktop entry but were not made the default. |

Global Windows hotkeys and Windows window-placement integrations are not reproduced. DRM/Widevine services, login-heavy sites and Wayland window positioning need separate validation. Windows registry tweaks, package debloat, system-wide firewall controls and DNS-to-process attribution are not available. ## Local installation

The installed apps are under `~/.local/share/axentra/apps/<app>`. Start with **Axentra Command** in the Zorin menu to open the suite. Previous app directories are retained for rollback. Profiles, vaults, documents and mail are separate from binaries. Startup and default associations remain opt-in.

Build instructions live with the private source repositories. The shared installer is in Axentra Command's `tools/linux` directory. It installs for the current user without sudo; system-wide packaging is separate.

## Validation boundaries

Automated checks used disposable profiles and test data. A successful startup does not establish that every feature has parity with Windows. Real mail authorization, physical USB security-key authentication, optional conversion/OCR tools, Wayland behavior and extended network capture need further validation. CrystalWire's sampled TCP view and Ghost's GNOME catalog have explicitly narrower scope than their Windows implementations.
