## Local installation

The installed apps are under `~/.local/share/axentra/apps/<app>`. Start with **Axentra Command** in the Zorin menu to open the suite. Previous app directories are retained for rollback. Profiles, vaults, documents and mail are separate from binaries. Startup and default associations remain opt-in.

Build instructions live with the private source repositories. The shared installer is in Axentra Command's `tools/linux` directory. It installs for the current user without sudo; system-wide packaging is separate.

## Validation boundaries

Initial automated checks used disposable profiles and test data. Ghost 0.1.5 additionally used live desktop preference apply/undo tests with disposable journals; all original settings were restored. A successful startup does not establish that every feature has parity with Windows. Real mail authorization, physical USB security-key authentication, optional conversion/OCR tools, Wayland behavior and extended network capture need further validation. CrystalWire's sampled TCP view and Ghost's session-matched desktop catalog have explicitly narrower scope than their Windows implementations.
