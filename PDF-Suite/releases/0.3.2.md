## What's new

- **Upgrades in place.** When a new installer runs (.exe or MSI), it closes a running Axentra, installs over
  the old version and reopens Axentra afterwards.
  - Open, unsaved documents are kept for recovery and offered back, so no "Save changes?" prompt blocks the
    update.
  - Unchanged files are left alone.
  - Your folder, Start menu entry and options are kept.
  - The licence page is skipped.
- **Forced default PDF app (optional).** For internal and managed PCs, Axentra can be made the default PDF
  app with Windows' default-associations policy, which applies at every sign-in. Uninstalling removes it.
  - .exe installer: choose *Install for all users* and tick *Force Axentra PDF as the default PDF app*.
  - MSI: `msiexec /i AxentraPDF-0.3.2.msi FORCEDEFAULTPDF=1`.

  Microsoft documents this policy for Windows Pro, Enterprise and Education.
- **Default PDF app, without forcing it.** Axentra registers with Windows, so it appears under *Open with*
  and in *Settings → Default apps*. Three places open Windows' own page for Axentra:
  - the installer's last page (ticked by default)
  - the first launch
  - *Help → Make Default PDF App*

### Also in this version

- **Ribbon:** laid out like the major commercial PDF editors.
- **Compress PDF:** three levels (Extreme, Recommended, Less), each showing its real resulting size, and
  Compress Files for batches.
- **Installers:** an MSI alongside the .exe.
- **Signing:** password-protected PDFs can be signed.
- **Forms:** fixes for radio-button groups and tab order.
- **Text editing:** keeps alignment and mixed fonts and colours, and editing OCR'd scans now replaces the
  scanned words.

## Known limitations

- **No code signing yet:** Windows SmartScreen warns on first run (choose *More info → Run anyway* after
  checking the checksum).
- **Signed documents:** saving a digitally signed document invalidates its signatures. You're warned first;
  sign last.
- **PDF/A:** needs Ghostscript and is best-effort.
