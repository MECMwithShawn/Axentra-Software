## What's new

- **Default PDF app.** Axentra now registers itself with Windows like other PDF editors. It shows up under
  *Open with* and in *Settings → Apps → Default apps*.
- **Making it the default.** Windows lets only you choose the default app, so no installer can do this
  silently. Instead, three places open Windows' own page for Axentra, where **Set default** is one click:
  - the installer's last page, where the option "Make Axentra PDF my default PDF app" is ticked by default
  - the first launch, which asks once (you can choose "Don't Ask Again")
  - *Help → Make Default PDF App*, at any time
- **Managed PCs.** The source includes `packaging/windows/default-associations.xml`. Applied through Group
  Policy, Intune or DISM, it makes Axentra the default PDF app with no prompt.

Everything else is as in [0.3.0](0.3.0.md).

## Upgrading from 0.3.0

Run the new installer; it replaces 0.3.0 in place.
