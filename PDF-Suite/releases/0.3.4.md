## What's new

- **PDF file icon.** PDF files get their own icon, a document with a teal PDF badge, separate from the
  Axentra app icon.
  - Styles: *Flat* (the default), *Glossy*, or the app's own icon.
  - Choosing in the installer: the .exe has a new page with a preview of each icon. It remembers your choice
    on upgrades. For the MSI, use `PDFICON=flat` or `PDFICON=glossy`.
  - Changing it later: *File → Preferences → Windows*. No administrator rights are needed.
- **Preferences → Windows** also has *Make Axentra PDF the Default PDF App*.

### From 0.3.3

- **Upgrades in place.** When a new installer runs (.exe or MSI), it closes a running Axentra, installs over
  the old version and reopens Axentra afterwards.
  - Open, unsaved documents are kept for recovery and offered back, so no "Save changes?" prompt blocks the
    update.
  - Unchanged files are left alone.
  - Your folder, Start menu entry and options are kept.
  - The licence page is skipped.
- **Forced default PDF app.** The installer now always installs for all users, and *Force Axentra PDF as
  the default PDF app* is ticked by default. It applies Windows' default-associations policy: sign out and
  back in once to finish. Untick it to only offer Windows' own Default apps page instead. The MSI forces it
  too; to turn that off, install with `msiexec /i AxentraPDF-0.3.4.msi FORCEDEFAULTPDF=0`. Uninstalling
  removes the policy. Microsoft documents the policy for Windows Pro, Enterprise and Education.
- **One copy only.** The installer removes an older "just for me" copy, or an MSI install, so exactly one
  Axentra remains.
- **Title bar:** a normal hyphen instead of an em dash ("file.pdf - Axentra PDF").
- **Default PDF app, without forcing it** (option unticked). Axentra registers with Windows, so it appears under *Open with*
  and in *Settings → Default apps*. Three places open Windows' own page for Axentra:
  - the installer's last page (ticked by default)
  - the first launch
  - *Help → Make Default PDF App*

### Also in this version

- **Ribbon:** laid out like the major commercial PDF editors.
- **Compress PDF:** three levels (Extreme, Recommended, Less), each showing its real resulting size, and
  Compress Files for batches.
- **Installers:** an MSI alongside the .exe.
- **Signing:** password-protected PDFs can be signed.
- **Forms:** fixes for radio-button groups and tab order.
- **Text editing:** keeps alignment and mixed fonts and colours, and editing OCR'd scans now replaces the
  scanned words.

## Known limitations

- **No code signing yet:** Windows SmartScreen warns on first run (choose *More info → Run anyway* after
  checking the checksum).
- **Signed documents:** saving a digitally signed document invalidates its signatures. You're warned first;
  sign last.
- **PDF/A:** needs Ghostscript and is best-effort.
