## What's in it

- **Borderless browser windows** for any site, with controls that appear when you hover the top edge: back, forward,
  reload, address, pin on top, open in Edge, minimize, maximize, close
- **Always on top:** pin any window above other apps
- **Spaces:** named layouts that remember every window's site, position, size and pin. Switch, create, rename and
  delete them from the tray
- **One shared profile:** sign in to each site once
- **Global shortcuts:** `Ctrl+Alt+N` opens a new window and `Ctrl+Alt+Space` hides or shows all of them. Media keeps
  playing while they're hidden
- Pop-ups and sign-in windows open as Spaces windows; full-screen video
- **Tray icon** and an optional *start with Windows*
- **`axentra-spaces://` links,** used by Axentra Horizon 0.3.10 and later (*Settings → Board → Open new windows in
  Axentra Spaces*)
- Per-user installer: no administrator rights needed; a clean uninstall from Windows Settings

## Known limitations

- Not code-signed yet: SmartScreen may warn on first run (*More info → Run anyway*).
- Windows only.
- Each window runs its own browser renderer, so many open windows use memory like many browser tabs.
