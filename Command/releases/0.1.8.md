## What's in it

- **Your apps:** a card for every installed Axentra app with its version, install scope, running state and service
- **Get more apps:** install the apps you don't have from this repository's releases. Each download is checked
  against GitHub's SHA-256 for that file before Setup runs; a mismatch is deleted, and a file without a published
  checksum is never run
- **Updates** for installed apps when a newer release is published
- **One tray icon for the suite:** apps hide their own icons while Command runs and their actions move into
  Command's tray menu; their icons come back if Command closes
- **Alerts:** red or amber dot on the tray icon when an app reports something that needs you
- **Start with Command:** choose which apps start when you sign in; apps already running are skipped
- **Quick launch** from the search box (`Ctrl+K`, Enter)
- **Add app / Edit** for your own entries
- Per-user installer: no administrator rights needed; a clean uninstall from Windows Settings

## Known limitations

- Not code-signed yet: SmartScreen may warn on first run (*More info → Run anyway*).
- Windows only.
- Apps appear under *Get more apps* only once they have a release in this repository.
- The Horizon extension can't have a Windows tray icon of its own; it's listed in Command's menu only.
