Passkey PRF feasibility test

Can an iPhone passkey produce a stable secret on this PC that could unlock a vault? Nothing leaves this machine, and no real vault is touched.

Steps
  1. Register: when Windows asks where to save the passkey, choose iPhone, iPad, or Android device and scan the QR code with your iPhone camera.
  2. Unlock: choose the iPhone again. The first run wraps a random test key. Later runs must unwrap the same key.
  3. Run Unlock two or three times. A match each time means the approach works.
