# Axentra Vault Design Handoff

1. Unzip this folder.
2. In the coding agent using **Opus 5.5**, open the existing Axentra Vault repository.
3. Attach `floating_modular_concept.png` as the primary reference, `fully_custom_concept.png` as optional secondary reference, and `OPUS_IMPLEMENTATION_BRIEF.md` as the task instructions.
4. Ask Opus to inspect the app, propose its change plan and build the shell behind a reversible UI/theme switch.
5. Require a successful Windows build, screenshots and review of locked-vault privacy before accepting the implementation.

Do not copy the concept's wallpaper, OS taskbar, example secrets or sample security claims into production UI.
