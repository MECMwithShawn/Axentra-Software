## What's in it

- **220 checks in 14 areas,** each explained, with its risk (safe, moderate, advanced) and side effects
- **Recommended and Strict profiles,** or pick setting by setting
- **Exact undo** of every registry value, service, scheduled task, firewall rule and hosts entry Ghost changed
- **Drift watch:** re-applies settings that Windows updates turn back on, and logs each time
- **Live monitor** of telemetry lookups per app, with [Axentra CrystalWire](../../CrystalWire/)
- **Network-wide blocking** through CrystalWire and Pi-hole, or this PC's hosts file, or an exported blocklist
- Settings Windows protects (User Choice Protection Driver) are shown as *Blocked by Windows*, with alternatives
- Optional System Restore point before changes
- Tray icon that hides while Axentra Command hosts the suite's tray
- New Axentra *Glass + Precision* icon

## Known limitations

- Not code-signed yet: SmartScreen may warn on first run (*More info → Run anyway*).
- Some policies only take full effect on Windows Enterprise or Education; those items say so.
- Removed apps can't be reinstalled by undo; get them back from the Microsoft Store.
- Windows only.
