# Ghost 0.1.5 Linux development preview

Documentation updated 2026-10-18; settings validation performed 2026-10-17 on Zorin OS 18.1 with XFCE. This describes a local QtWebEngine suite build, not a published Linux installer or a new Windows release.

The catalog now includes 27 entries: 18 GNOME/GTK preferences, eight XFCE preferences and one optional NetworkManager property. Desktop detection prevents inactive GNOME preferences from being counted as active XFCE protection. The interface uses compact rows, consistent status badges and expandable impact/undo details.

Live round trips passed for 18 GNOME/GTK preferences and eight XFCE preferences; all original settings were restored. GNOME results verify preference storage, not compliance by XFCE. Seventeen suite engine/API tests passed. No configured connectivity-check endpoint was available, so mutation/undo of that property remains unverified. Physical device, suspend/resume, media-insertion and packet-level behavior still need validation.

GNOME undo preserves the prior user override or its absence. XFCE undo restores the saved effective value. The private-source and installed suite were used for verification; no application source, user journal or settings snapshot is included in this public documentation update.
